# Offload

**Локальная модель-помощник для Claude Code и других IDE.** Offload — приложение для Windows, которое живёт в трее, само ставит [llama.cpp](https://github.com/ggml-org/llama.cpp), скачивает модель для программирования, настраивает агент [OpenCode](https://opencode.ai) и подключается к вашим IDE как MCP-сервер. Claude Code (а также Cursor, VS Code, Codex, Gemini CLI и другие) получает набор инструментов, через которые может **делегировать рутинную работу бесплатной локальной модели** и тратить меньше облачных токенов.

Никакого Docker, WSL, Python и Node.js — один `Offload.exe`, всё ставится в профиль пользователя без прав администратора.

## Зачем это нужно

Самые дорогие токены в работе облачного агента — это:

1. **чтение больших файлов и логов** — каждый прочитанный файл остаётся в контексте и перечитывается на каждом следующем шаге;
2. **написание кода** — выходные токены в 5 раз дороже входных.

Offload забирает оба пункта на локальную модель:

- сервер **сам читает файлы** и отдаёт облачной модели только короткий ответ (вопрос по 2000 строкам кода стоит ~800 токенов вместо ~20 000);
- сервер **сам пишет файлы на диск** (тесты, DTO, заготовки, механические правки) и возвращает только сводку: сколько строк, прошла ли проверка командой;
- ответы компактные, с подписью, сколько облачных токенов удалось сэкономить. Общая статистика — в окне «Состояние».

Планирование, архитектура, сложная отладка и финальная проверка остаются за Claude — инструкции MCP-сервера прямо говорят ему, что делегировать, а что нет.

## Возможности

- **Мастер установки** на русском: определяет видеокарту, объём видеопамяти, драйвер и ОЗУ, подбирает сборку llama.cpp (CUDA 12/13, Vulkan, ROCm, SYCL, CPU) и модель, которая поместится.
- **Основная модель — Qwen3.8-27B** (лучшее качество кода среди локальных моделей): Q6 для 32+ ГБ видеопамяти, Q4 для 24 ГБ, IQ3 для 16 ГБ. Для карт слабее мастер предложит быстрые MoE (Qwen3.6-35B-A3B, Ornith) и 9B-модели.
- **Каталог актуальных моделей** (Qwen3.8/3.6/3.5, Ornith, gpt-oss, Qwen3-Coder-Next, Devstral и др.) с точными файлами, контрольными суммами SHA-256 и оценкой «поместится ли в видеопамять». MoE-модели автоматически выгружают часть экспертов в ОЗУ — 35B-модель работает даже на 8–12 ГБ видеопамяти.
- **Загрузка с докачкой** и проверкой контрольных сумм; можно добавить свой GGUF-файл.
- **llama-server под управлением трея**: автозапуск, перезапуск при сбое, выгрузка модели при простое, журнал, статус видеопамяти.
- **OpenCode** ставится автоматически и настраивается на локальную модель — для многошаговых правок агентом.
- **Подключение к IDE в один клик**: Claude Code, Claude Desktop, Cursor, VS Code (Copilot), Copilot CLI, Windsurf/Devin, Cline, Roo Code, Kilo Code, Zed, Gemini CLI, OpenAI Codex, JetBrains Junie, Continue, Visual Studio, Kiro, Trae, Qoder. Конфигурации правятся бережно (с резервной копией и сохранением комментариев).
- **Для Claude Code** дополнительно: навык (skill) с правилами делегирования, опциональное «строгое» правило, субагент и разрешения на инструменты чтения без подтверждения.
- **Безопасность**: сервер слушает только `127.0.0.1` с ключом API; MCP-инструменты не читают секреты (`.env`, ключи, сертификаты), пишут только внутри рабочей папки, проверочные команды — только из белого списка; любую правку можно откатить.
- Интерфейс трея и все окна — **полностью на русском**.

## Инструменты MCP

| Инструмент | Что делает | Меняет файлы |
|---|---|---|
| `local_ask_files` | Ответ на вопрос по файлам/папкам/маскам, которые сервер читает сам (объяснить модуль, найти использование, первичное ревью) | нет |
| `local_summarize_log` | Выжимка из большого лога сборки/тестов: что упало, первая ошибка, вероятная причина | нет |
| `local_review_diff` | Первичное ревью `git diff` (staged/unstaged/ref) | нет |
| `local_commit_message` | Сообщение коммита по diff, прочитанному на стороне сервера | нет |
| `local_write_file` | Новый файл по спецификации (тесты, DTO, фикстуры, документация) + проверочная команда | да |
| `local_edit_files` | Механическая правка списка файлов (прямая перезапись или агент OpenCode) + проверка, снимок для отката | да |
| `local_job` | Статус, diff или откат задачи записи/правки | да (откат) |
| `local_status` | Состояние локальной модели, скорость, экономия токенов | нет |

В Claude Code инструменты называются `mcp__offload__<имя>`. Пример запроса: *«используй offload, чтобы написать xUnit-тесты для `ParseHeader` в новом файле `tests/ParserTests.cs` и проверить их `dotnet test`»*.

## Установка

1. Скачайте `Offload-Setup-<версия>.exe` (или просто `Offload.exe`) со страницы [Releases](https://github.com/Kelll31/offload/releases).
2. Запустите — откроется мастер настройки. Он предложит сборку llama.cpp и модель под ваше железо, скачает всё нужное и подключит найденные IDE.
3. Перезапустите Claude Code (или выполните `/mcp`) — появится сервер `offload`.

Требования: Windows 10 1809+ / Windows 11 x64, желательно видеокарта NVIDIA/AMD/Intel с 8+ ГБ видеопамяти (работает и на процессоре, но медленно), 10–30 ГБ свободного места под модель. Для сборок llama.cpp нужен Visual C++ Redistributable — мастер установит его сам (потребуется подтверждение UAC).

### Ручное подключение к любой IDE

```json
{
  "mcpServers": {
    "offload": {
      "command": "C:\\Users\\<вы>\\AppData\\Local\\Programs\\Offload\\Offload.exe",
      "args": ["--mcp"]
    }
  }
}
```

Точный путь и готовый JSON есть на вкладке «Интеграции» — кнопка «Копировать».

## Где что лежит

| Путь | Что |
|---|---|
| `%LOCALAPPDATA%\Programs\Offload\Offload.exe` | программа (при установке через установщик) |
| `%LOCALAPPDATA%\Offload\config.json` | настройки |
| `%LOCALAPPDATA%\Offload\llama.cpp\` | сборка llama.cpp |
| `%LOCALAPPDATA%\Offload\models\` | модели GGUF (папку можно сменить) |
| `%LOCALAPPDATA%\Offload\opencode\` | OpenCode и его изолированная конфигурация |
| `%LOCALAPPDATA%\Offload\logs\` | журналы приложения, llama-server и MCP |
| `%LOCALAPPDATA%\Offload\usage.jsonl` | статистика обращений и экономии |

Переменная окружения `OFFLOAD_HOME` переносит папку данных (портативный режим).

## Сборка из исходников

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download/dotnet/10.0).

```powershell
.\scripts\build.ps1              # тесты + publish\Offload.exe (самодостаточный, ~60 МБ)
.\scripts\build.ps1 -Installer   # + установщик dist\Offload-Setup-<версия>.exe (нужен Inno Setup 6 или 7)
```

Проверка MCP-сервера без IDE:

```powershell
node scripts\mcp-smoke.mjs .\publish\Offload.exe local_status '{}'
```

### Структура решения

| Проект | Назначение |
|---|---|
| `Offload.Core` | пути, настройки, журнал, загрузчик с докачкой, определение железа, IPC, статистика |
| `Offload.Llama` | релизы llama.cpp, установка, управление llama-server, клиент OpenAI-совместимого API |
| `Offload.Models` | каталог моделей, оценка видеопамяти, Hugging Face, чтение GGUF |
| `Offload.OpenCode` | установка и изолированная настройка OpenCode, неинтерактивный запуск агента |
| `Offload.Integrations` | регистрация MCP-сервера в IDE, навык и разрешения Claude Code |
| `Offload.Mcp` | stdio MCP-сервер (`Offload.exe --mcp`) и инструменты делегирования |
| `Offload.App` | трей, панель управления, мастер настройки (WinForms, русский интерфейс) |

## Удаление

Удалите программу через «Параметры → Приложения». Деинсталлятор отключит Offload от всех IDE и спросит, удалять ли скачанные модели.
